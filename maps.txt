# Cardputer Maps: tile sources
#
# One URL per line. {z} {x} {y} are substituted. Lines starting with # are comments.
#
# The order here is the order shown in :maps. Priority is up to you.
#
# HTTPS sources are selectable only with an SD card, because TLS costs about
# 38 KB of contiguous heap.
#
# The name shown in the list is derived from the URL: /styles/<id>/ if present,
# else the path segment before {z}, else "(no name)".
#
# ---- Adding a source --------------------------------------------------------
# Add one line to this file and send a PR. No C changes are needed:
# tools/gen-map-defaults.py generates src/map_defaults.h at build time.
#
# After adding a line, bump maps-version at the bottom by one. Users who already
# have a maps.txt on their SD card receive the new entries as appends only,
# while their own edits are left untouched.
# -----------------------------------------------------------------------------
